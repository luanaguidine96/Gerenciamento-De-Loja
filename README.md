# Gerenciamento de Loja

Aplicação web desenvolvida em **Java com Spring Boot** para gerenciamento de produtos.

## Tecnologias

- Java 26
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- HTML, CSS e JavaScript
- Maven

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- API REST
- Persistência de dados no MySQL
- Interface web integrada à API

## Sobre o projeto

Projeto desenvolvido para fins de estudo e portfólio, aplicando conceitos de desenvolvimento backend, APIs REST, persistência de dados e integração com frontend.
